# LinkedIn Outreach Sequence — Topmate Bookings

**Important:** LinkedIn's User Agreement prohibits automated sending of connection requests or
messages — accounts that do this risk restriction or permanent ban. These messages are meant
to be copy-pasted and sent by you, manually, from your own logged-in LinkedIn account. After
each send, update the contact's `Stage` in `tracker.xlsx`.

Placeholders: same as `email_templates.md` — `[FIRST_NAME]`, `[YOUR_NAME]`, `[SERVICE]`,
`[TOPMATE_LINK]`, `[SPECIFIC_HOOK]`, `[SOCIAL_PROOF]`.

Cadence: Connection note → once accepted, wait a day or two, then Message 1 → if no reply after
~5 days, Message 2 (final, low-pressure). Stop on reply or booking.

---

## Connection Request Note (300 char limit)
```
Hi [FIRST_NAME] — [SPECIFIC_HOOK]. Would love to connect!
```
Keep this short and non-salesy — the ask is just to connect, not to book anything yet.

---

## Message 1 — After connection accepted
**Send:** 1–2 days after they accept
```
Hey [FIRST_NAME], thanks for connecting!

[SPECIFIC_HOOK]. I run [SERVICE] sessions on Topmate, [SOCIAL_PROOF] — thought it might be
useful given [reason tied to their situation].

Booking link if you'd like to grab a slot: [TOPMATE_LINK]

No pressure either way — happy to just stay in touch.
```

---

## Message 2 — Final follow-up
**Send:** ~5 days after Message 1, if no reply
```
Hi [FIRST_NAME], just circling back in case this got buried in your inbox.

If [SERVICE] is useful down the line, the link's always open: [TOPMATE_LINK]

Either way, good luck with [something specific to their goals/role]!
```

---

## Notes
- Personalize the connection note per person — LinkedIn already restricts generic bulk
  connection requests, and unpersonalized notes get ignored or reported more often.
- Space out connection requests manually (LinkedIn has its own daily limits, roughly 100/week
  for standard accounts) — sending too many in a short window risks a temporary restriction.
- Never repurpose someone's public post content into the hook without adding your own
  perspective — reference it, don't quote it at length.
